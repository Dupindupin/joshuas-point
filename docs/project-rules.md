# Joshua's Point — Project Rules

Version: 1.0

---

# Purpose

This document defines the rules for everyone working on Joshua's Point.

These rules apply to developers, designers, AI assistants, and future contributors.

If a decision conflicts with these rules, these rules win.

---

# Our Mission

Joshua's Point is not simply a villa website.

It is the digital expression of a place built from love, memories, architecture, and nature.

Every decision should strengthen that feeling.

---

# Core Principles

1. Nature is always the hero.

2. Architecture frames the landscape.

3. The website should feel calm.

4. Luxury is quiet.

5. Simplicity is strength.

6. White space is part of the design.

7. Photography tells the story.

8. Technology should disappear behind the experience.

9. Guests should feel welcomed, never sold to.

10. Every page should leave visitors calmer than before.

---

# Design Rules

Always follow the Design System.

Never invent new colors without approval.

Never invent new typography.

Never create inconsistent spacing.

Never create components outside the Design System.

If a new component is required:

Design it first.

Document it.

Then implement it.

---

# Development Rules

Write clean code.

Prefer readability over cleverness.

Keep components small.

Reuse existing components whenever possible.

Never duplicate code unnecessarily.

Accessibility is required.

Performance is required.

Responsive design is required.

---

# Content Rules

Write like a host.

Never write like a salesperson.

Describe experiences.

Do not exaggerate.

Avoid marketing clichés.

Every sentence should feel honest.

---

# Photography Rules

Use real photography whenever possible.

Natural light is preferred.

Avoid heavy editing.

Avoid artificial poses.

Capture moments.

Not perfection.

---

# Motion Rules

Motion should support the story.

Never distract.

Animations should feel natural.

Transitions should feel slow and elegant.

Visitors should remember the place.

Not the animation.

---

# Theme Rules

Joshua's Point has two atmospheres.

Morning

Evening

Not Light Mode and Dark Mode.

Both themes should feel warm.

Never cold.

# Decision Process

Before implementing any feature ask:

Does this follow the Design System?

Does this support the Joshua's Point experience?

Does it make the experience calmer?

Does it make the interface simpler?

If the answer is "No",

stop and rethink.

---

# Quality Standard

Nothing is shipped because it is finished.

It is shipped because it feels like Joshua's Point.

---

# Long-Term Goal

Build one of the most beautiful, authentic, and timeless hospitality websites on the web.

The goal is not to impress.

The goal is to make people feel something.

If visitors close the website already imagining themselves standing on the deck, we have succeeded.

---

# The Final Question

Before approving any design, animation, photograph, sentence, or feature, ask one simple question:

**Would this still feel right ten years from now?**

If the answer is yes,

it belongs at Joshua's Point.

If the answer is no,

keep refining.
