# Joshua's Point — Content Backlog

## Purpose

This is the master editorial production board for the Southern Negros Guide. It tracks work from
commissioning through research, photography, verification, writing, search preparation,
publication, and later review.

The backlog is intentionally conservative. A place appears by name only when it has already been
approved elsewhere in the project. Unresearched opportunities remain labelled placeholders until
fieldwork confirms the subject, location, access, safety, and editorial value.

Use this board with:

- [`EDITORIAL_CONTENT_SYSTEM.md`](./EDITORIAL_CONTENT_SYSTEM.md)
- [`DESTINATION_SYSTEM.md`](./DESTINATION_SYSTEM.md)
- [`SANITY_CONTENT_MODEL.md`](./SANITY_CONTENT_MODEL.md)
- [`LAUNCH_ROADMAP.md`](./LAUNCH_ROADMAP.md)

### Board conventions

| Term | Meaning |
| --- | --- |
| `P0` | Required for the next launch gate or needed to validate the production standard. |
| `P1` | Important for the first balanced guide edition. |
| `P2` | Valuable expansion after the launch collection is coherent. |
| `P3` | Long-term idea; do not commission without a clear editorial reason. |
| `Backlog` | Approved as a production opportunity but not commissioned. |
| `Researching` | Sources, access, fieldwork, and editorial angle are being established. |
| `Drafting` | Reporting is sufficient for a first written draft. |
| `In Review` | Editorial, factual, photographic, accessibility, and SEO review is active. |
| `Ready` | Every publishing gate is complete. |
| `Published` | Live with a recorded publication and next-review date. |
| `—` | Not started or not yet established. It never means “not required.” |

### Rules for maintaining this board

1. Never replace `—` with “Verified” without a source record and verification date.
2. Never mark Photography complete until rights, credits, captions, alt text, crops, and files are
   approved.
3. Never mark Story Written complete while placeholder prose remains.
4. Never mark Published complete merely because a schema seed or technical test is live.
5. Add a named place only after commissioning approval; use a placeholder during discovery.
6. Keep one canonical production row per piece. Category queues later in this document point back
   to that row rather than creating a second status record.
7. Move published work into maintenance rather than removing it from the board.
8. Record review dates in Sanity. This document tracks progress; it is not the factual source of
   truth.

### Premium guide production gates

1. Approve the edition brief and named editorial owner.
2. Confirm what remains free and public.
3. Complete field reporting and fact verification.
4. Clear photography, contributor, map, and third-party rights.
5. Edit and proof the complete edition.
6. Produce and test accessible screen and print files.
7. Define version, corrections, customer updates, support, licence, and refund policy.
8. Re-evaluate payment and delivery providers using current eligibility, fees, tax, privacy, and
   accessibility information.
9. Run a private reader and field-use test.
10. Approve commerce only after the product itself is complete.
