# Joshua's Point — Site Settings and House Content Entry Checklist

**Document type:** Internal Sanity Studio content-entry helper
**Scope:** `siteSettings` and `housePage` singletons
**Public website copy:** No

## Purpose

Use this checklist while entering the already approved Joshua's Point material into Sanity Studio.
It does not replace the source documents, approve public wording, or provide missing copy.

Authoritative sources:

## 1. Site Settings

Open **Website → Site Settings**. Complete the existing singleton; do not create another document.

### Identity

- [ ] `siteTitle` contains the approved official name.
- [ ] `siteUrl` contains the approved canonical HTTPS origin.
- [ ] `siteDescription` contains approved factual wording from an existing source.
- [ ] `defaultLocale` remains the approved current authoring locale.
- [ ] `primaryLogo` uses the approved horizontal production asset.
- [ ] `compactLogo` uses the approved JP compact mark.
- [ ] `faviconImage` uses the approved favicon reference.
- [ ] `appIconImage` uses the approved application icon reference.
- [ ] Every uploaded brand image has an intentional accessibility treatment.
- [ ] No logo artwork, colour, typography, spacing, or proportions have been changed.

Approved local asset sources are held in `web/public/brand/`. The logo specification remains the
authority for asset selection and use.

### Contact

- [ ] `contactDetails.email` uses the confirmed monitored public address.
- [ ] `contactDetails.address` uses only the approved public location information.
- [ ] `contactDetails.phone` remains empty unless an approved public number exists.
- [ ] `contactDetails.phoneHref` is present only when a phone number is approved and uses the
      required international `tel:` format.
- [ ] `contactDetails.whatsappUrl` remains empty unless Tobias has separately approved the channel.
- [ ] `contactDetails.mapUrl` is entered only when an approved public map destination exists.
- [ ] `contactDetails.inquiryNote` is entered only when the response guidance is approved.
- [ ] No private coordinates, access instructions, or credentials are stored here.

### Property location

- [ ] `propertyLocation.label` matches the approved public location.
- [ ] `propertyLocation.coordinates` are entered only at the precision Tobias has approved for
      public use.
- [ ] `propertyLocation.directionsUrl` uses an approved public directions destination.
- [ ] The location does not use Cauayan, Negros Occidental or Siaton as Joshua's Point's location.

### Primary navigation

- [ ] Every item points to an existing public route or supported published document.
- [ ] Labels and order match the approved public navigation.
- [ ] Unfinished or unpublished routes are absent.
- [ ] External links use complete approved HTTPS destinations.
- [ ] The list remains deliberately small.

### Footer

- [ ] `footer.introduction` uses the approved quiet closing statement.
- [ ] `footer.navigationGroups` contain only approved public destinations.
- [ ] Link labels, group titles, and ordering match the current approved footer.
- [ ] `footer.contactDetailsOverride` remains empty unless the footer genuinely needs different
      public contact details.
- [ ] `footer.socialLinks` contain only Tobias-approved official profiles.
- [ ] Each social platform appears only once.
- [ ] `footer.legalLinks` point to the existing Privacy and Terms routes.
- [ ] `footer.copyrightText` does not include a hardcoded year.

### Booking

- [ ] `bookingLinks.enabled` reflects the approved current booking state.
- [ ] `bookingLinks.primary` is entered only when the destination is approved.
- [ ] `bookingLinks.inquiry` points to the approved enquiry destination when used.
- [ ] `bookingLinks.disclosure` is entered only for approved external-booking guidance.
- [ ] No payment method, price, condition, booking engine, or external service is inferred.

### Social presence

- [ ] `squareProfileImage` uses the approved square profile asset.
- [ ] `instagramHighlights` contains no more than three approved posts, or remains empty.
- [ ] Facebook and Instagram URLs match the owner-confirmed official accounts.
- [ ] Unsupported or unconfirmed platforms remain absent.

### Site-wide SEO

- [ ] `defaultSeo.metaTitle` is approved.
- [ ] `defaultSeo.metaDescription` is approved and factual.
- [ ] Optional social title and description fields are used only when approved.
- [ ] `defaultSocialImage` is an approved 1200 × 630 image.
- [ ] The social image has final rights, crop, credit, alt text, and privacy approval.
- [ ] `defaultSeo.noIndex` is not enabled for the intended public production site.
- [ ] No private story, unsupported claim, or generic hotel language appears in metadata.

## 2. House content entry order

Open **Website → The House**. Keep `workflowStatus` as **Draft** throughout entry and review.

### 1. Hero

- [ ] Enter approved `eyebrow`.
- [ ] Enter approved `title`.
- [ ] Enter approved `introduction` from the current House presentation/source record.
- [ ] Add one approved landscape-led `image`.
- [ ] Complete image alt text, credit, crop/hotspot, rights, and privacy review.
- [ ] Match any named landmark to the actual selected frame.

Do not use the reported first reaction as a testimonial unless Tobias explicitly approves that
public use.

### 2. Opening Reflection

- [ ] Enter the approved `heading`.
- [ ] Enter the approved short `body`.
- [ ] Confirm the wording demonstrates Homy, Connected to nature, and Peaceful through approved
      observation rather than a promise.
- [ ] Confirm no private family history or name-origin material appears.

### 3. Shared Heart of the House

- [ ] Enter approved `heading`.
- [ ] Enter approved `body` about verified everyday use of the connected shared spaces.
- [ ] Add one or two ordered `images` only when each contributes a distinct role.
- [ ] Confirm kitchen, dining, living room, deck, and outside relationships against the selected
      frame.
- [ ] Confirm any visible people have appropriate consent.
- [ ] Remove details that imply acoustic, privacy, capacity, or performance guarantees.

### 4. View

- [ ] Add one verified panoramic `image` from a real position at or immediately around the house.
- [ ] Add `caption` only when verified factual context helps the reader.
- [ ] Add a concise, non-sensitive `verificationNotes` summary.
- [ ] Match Bohol Sea, Apo Island, Siquijor Island, and Mount Talinis individually to the final
      frame before naming them.
- [ ] Keep coordinates, access details, raw evidence, and private memories out of verification
      notes.

### 5. Indoor Outdoor Story

- [ ] Enter approved `heading`.
- [ ] Enter approved `body` using only verified relationships and observed use.
- [ ] Add between one and three controlled story images.
- [ ] Use each role no more than once: **Open threshold**, **Deck and shelter**, **Pool
      relationship**.
- [ ] Confirm the photographs represent ordinary use and true spatial alignment.
- [ ] Do not publish the deck dimension until its measurement basis is approved.
- [ ] Do not infer roof, shade, ventilation, drainage, or weather performance from photographs.

### 6. Daily Rhythms

Each moment is optional. Leave a moment empty until both its approved observation and truthful
photograph are ready.

#### Morning

- [ ] Enter the approved `body` only.
- [ ] Add a photograph verified as Morning.
- [ ] Confirm the visible sea or mountain relationship against the frame.

#### Rain

- [ ] Enter the approved `body` only.
- [ ] Add a photograph that visibly records real rain or rainy conditions.
- [ ] Do not describe a clear or night image as Rain.

#### Evening

- [ ] Enter the approved `body` only.
- [ ] Add the approved Evening photograph.
- [ ] Verify capture context, ordinary use, editing, rights, and crop.

Do not convert one personal routine into a guaranteed guest routine. Do not guarantee weather,
quiet, light, visibility, or natural sounds.

### 7. Materials and Architecture

This entire section is optional.

- [ ] Enter `heading` only when at least one complete verified material story exists.
- [ ] Enter optional `body` only from approved source.
- [ ] Add between one and six verified material entries.
- [ ] Each entry has an approved `name` and `description`.
- [ ] Optional detail images are matched to the correctly identified material or element.
- [ ] Wood, concrete, roof sheets, sliding doors, systems, and architectural credits are included
      only at their approved level of detail.
- [ ] The phrase “stone detail on cement” is not entered as public terminology.
- [ ] No sustainability, sourcing, ventilation, thermal, maintenance, or performance claim exceeds
      its verification record.

If no entry meets these requirements, leave the section absent.

### 8. Closing Reflection

- [ ] Enter one approved concise `body`.
- [ ] Confirm the paragraph is grounded in a public-safe owner observation.
- [ ] Confirm there is no booking prompt, testimonial, private memory, or emotional guarantee.

### 9. House SEO

- [ ] `seo.metaTitle` is approved.
- [ ] `seo.metaDescription` accurately summarizes the visible House page.
- [ ] Optional `seo.socialTitle` and `seo.socialDescription` are approved.
- [ ] `seo.socialImage` is final and production-approved, or remains empty to inherit the approved
      Site Settings default.
- [ ] `seo.canonicalUrl` remains empty unless an intentional canonical override is required.
- [ ] `seo.noIndex` reflects the intended public publishing state.
- [ ] Metadata contains no private origin story, precise private location, unsupported
      architectural claim, or generic hotel language.

### 10. Governance

- [ ] `lastReviewedAt` records the material factual and privacy review date, not a proofreading
      date.
- [ ] Workflow remains **Draft** during entry.
- [ ] Move to **In Review** only when all retained public fields and images are ready for review.
- [ ] Move to **Approved** only after every publication requirement below is complete.

## 3. Photography requirements

### Required House photography

- [ ] Hero: defining house-within-landscape image.
- [ ] Shared Heart: one approved connected-space image; second image only if distinct.
- [ ] View: uninterrupted verified panoramic image.
- [ ] Indoor/Outdoor: at least one approved role image.
- [ ] Every retained Daily Rhythm moment: one truthful condition-specific image.

### Optional House photography

- [ ] Material/detail images only for verified entries.
- [ ] Human moments only when editorially necessary, public-safe, and fully consented.
- [ ] House-specific social image, otherwise inherit the approved Site Settings default.

### Asset checks for every retained image

- [ ] Production source or approved derivative is available.
- [ ] Photographer and rights holder are recorded.
- [ ] Publication, crop, derivative, and editing rights are confirmed.
- [ ] Capture context and material edits are recorded.
- [ ] Visible geography or material identity is verified before naming it.
- [ ] Desktop and mobile crops are approved.
- [ ] Informative alt text describes the approved crop.
- [ ] Caption is short, factual, and necessary when used.
- [ ] Privacy, consent, security, and metadata review is complete.
- [ ] Development photography is clearly marked and is not mistaken for final media.

### Known photography gaps

- [ ] Final View photograph.
- [ ] Final truthful Morning photograph.
- [ ] Final truthful Rain photograph.
- [ ] Wider definitive Hero, unless the current candidate is separately approved as sufficient.
- [ ] Shared Heart image with a clearer outside relationship, if required.
- [ ] Verified material/detail photography, if the optional Materials section is retained.

## 4. Required before publish

### Site Settings

- [ ] Every schema-required field is complete.
- [ ] Default SEO title and description are approved.
- [ ] Default social image is approved.
- [ ] Contact channels are monitored and public.
- [ ] Navigation, footer, social, and booking destinations have been tested.
- [ ] Brand assets use only approved artwork.
- [ ] No secrets or private coordinates are stored in Sanity.

### House

- [ ] Every public sentence is traceable to approved owner source or verified information.
- [ ] Required Hero, Opening Reflection, Shared Heart, View, Indoor/Outdoor, and Closing fields are
      complete.
- [ ] Every retained optional moment or section is complete; incomplete optional content is absent.
- [ ] View landmarks are matched to the selected photograph.
- [ ] Materials contains only verified entries.
- [ ] Image rights, credits, crops, accessibility, privacy, and responsive checks are complete.
- [ ] Development photography has not been mistaken for final photography.
- [ ] House meta description is complete.
- [ ] Studio-only verification notes contain no private or sensitive material.
- [ ] Private family information and the name origin are absent from copy, metadata, captions, alt
      text, previews, and image metadata.
- [ ] `lastReviewedAt` reflects the completed material review.
- [ ] `workflowStatus` is **Approved**.
- [ ] A post-entry comparison confirms that Sanity output preserves the approved House presentation.
