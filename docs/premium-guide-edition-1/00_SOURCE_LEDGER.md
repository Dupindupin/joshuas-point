# Southern Negros Premium Guide Edition 1 — Source Ledger

## Purpose

This ledger records which existing sources support the Edition 1 manuscript. It protects Tobias's
voice, prevents duplicated facts, and keeps legacy material from overriding later owner
corrections.

**Source review began:** 12 August 2026

## Authority order

1. Existing Southern Negros Guide: `https://guide.joshuaspoint.com/`
2. Existing Joshua's Point website: `https://joshuaspoint.com/`
3. Approved Tobias owner records in this repository
4. Verified public sources, only where history, nature, culture, or geography remains incomplete

Within that order, a later explicit owner correction overrides an older conflicting claim. The
older passage remains a migration source for useful structure and observations, not for superseded
facts.

## Known conflicts and exclusions

The legacy House page includes claims that conflict with later owner-confirmed records, including
floor area, room configuration, bed type, soaking tubs, and other amenity details. These claims are
not guide sources.

The existing guide includes Negros Occidental and Siquijor. Those entries are outside Edition 1.
Commercial directories, alternative accommodation, operator rankings, live prices, schedules, and
technical dive claims remain excluded unless the approved blueprint assigns them a specific,
reviewed role.
