# Joshua's Point — Components

Version: 1.0 (Living Document)

---

# Philosophy

Every component should feel like it belongs to the same family.

Visitors should never notice the interface.

They should notice the experience.

Components should be quiet.

Consistent.

Timeless.

---

# Primary Button

Feeling

Warm.

Inviting.

Confident.

Purpose

Primary actions.

Reserve.

Check Availability.

Explore.

Rules

Large click area.

Soft rounded corners.

Comfortable padding.

Never flashy.

---

# Secondary Button

Purpose

Secondary actions.

Read More.

View Gallery.

Discover.

Should always feel lighter than the primary button.

---

# Navigation

Simple.

Minimal.

Easy to understand.

Never overloaded.

The navigation should quietly guide people through the story.

---

# Cards

Cards are containers for stories.

Not decoration.

Use cards for:

Rooms.

Experiences.

Destinations.

Journal entries.

Cards should breathe.

Use generous spacing.

---

# Image Blocks

Photography is more important than decoration.

Allow images to dominate.

Never force images into tiny boxes.

Use different image sizes to create rhythm.

---

# Forms

Simple.

Friendly.

Only ask for what is necessary.

Every field should have a purpose.

The form should feel like an invitation to start a conversation.

Not like paperwork.

---

# Icons

Use icons only when they improve understanding.

Keep them simple.

Thin lines.

Architectural.

Avoid playful cartoon styles.

---

# Dividers

Subtle.

Often unnecessary.

Use white space instead.

When needed, use soft neutral colors.

---

# Footer

Calm.

Useful.

Never overloaded.

A quiet ending to the journey.

---

# Consistency

Every component should follow:

Typography

Spacing

Colors

Motion

Photography

Nothing should feel like it belongs to another website.

---

# Remember

A component is successful when visitors forget it exists.

They remember the experience instead.
