# Joshua's Point — Spacing

Version: 1.0 (Living Document)

---

# Philosophy

Space is part of the architecture.

The website should feel as open and calm as Joshua's Point itself.

We are not afraid of empty space.

White space allows the visitor to breathe.

---

# Design Principle

Every section should have room to exist.

Never place elements too close together.

The layout should feel relaxed.

Not crowded.

---

# Vertical Rhythm

Small spacing

8px

Used for:

Icons

Labels

Small UI elements

---

Medium spacing

16–24px

Used for:

Paragraphs

Lists

Buttons

Cards

---

Large spacing

48–64px

Used for:

Sections

Hero content

Image groups

Story blocks

---

Extra Large spacing

96–160px

Used for:

Page transitions

Major content sections

Homepage storytelling

---

# Content Width

Reading should be comfortable.

Never create paragraphs that are too wide.

Target width:

65–75 characters per line.

---

# Images

Images should have room around them.

Never stack too many images together.

One strong image is often better than six average ones.

---

# Cards

Cards should never touch.

Every card should feel independent.

Generous padding.

Rounded corners only where appropriate.

---

# Mobile

Reduce spacing carefully.

Never make mobile feel cramped.

Keep the same calm feeling.

---

# White Space

White space is not empty.

It is part of the design.

It creates rhythm.

It creates elegance.

It creates focus.

---

# Remember

If something feels crowded...

Remove something.

Don't make everything smaller.
