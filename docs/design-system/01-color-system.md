# Color System

## Philosophy

The colors are inspired by Joshua's Point itself.

Not trends.

Not tropical resorts.

The house.

The timber.

The sea.

The mountains.

The light.

## Rules

No pure white.

No pure black.

Always warm.

Always natural.

Colors support the photography.

They never compete with it.
