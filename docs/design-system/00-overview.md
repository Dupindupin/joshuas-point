# Joshua's Point Design System

Version: 1.0 (Living Document)

## Purpose

This design system defines the visual identity of Joshua's Point before implementation.

It ensures that every page, animation, photograph and component follows one consistent philosophy.

---

## Brand Personality

- Quiet
- Warm
- Architectural
- Natural
- Timeless
- Curious
- Personal
- Inviting
- Honest
- Confident
- Humble

---

## Design Philosophy

Architecture frames nature.

Nature is always the hero.

Luxury is calm.

White space is part of the experience.

Technology should disappear behind the story.

Guests should feel invited, never pressured.
