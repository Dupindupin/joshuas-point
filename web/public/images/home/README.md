# Home Development Photography Workspace

This directory contains temporary Joshua's Point photography for Home page visual development.

Every image here is:

- **development photography**;
- **not production approved**;
- **replace before launch**.

The files are role-specific copies of existing House development assets. The House originals must
not be moved, renamed, or modified. Copying a photograph into this workspace does not approve its
rights, credit, capture context, caption, crop, alt text, or final Home role.

Final approved Home photography will later be managed through Sanity so images can be replaced
without changing page components or layout.
