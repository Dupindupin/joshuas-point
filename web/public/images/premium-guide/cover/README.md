# Premium Guide cover concept

`southern-negros-cover-concept-v1.png` is an AI-generated visual-development concept for the local
Southern Negros Premium Guide prototype.

It is:

- placeholder concept imagery;
- not documentary evidence of one real Southern Negros location;
- not production-approved photography; and
- replaceable before launch when suitable owner photography is selected.

The image establishes the intended cover relationship among foreground water, rural landscape,
mountains, sea, and distant islands. The same master image is responsively cropped by the existing
cover component for desktop and mobile preview use.
